# Parkour-System-UE5
This is a fully modular Parkour System designed for integration into any project. It provides smooth and responsive player movement across obstacles and walls, built with Actor Components for maximum flexibility.

Features

🎮 Three Levels of Parkour Actions

Advanced parkour moves (climbing, vaulting, mantling, etc.)

🔌 Modular Actor Component
Drop-in integration into any character blueprint or pawn.
No dependency on custom player classes.

⚙️ Customizable
Tweak action settings via exposed variables.
Extend with additional moves and animations.

🏗️Installation
Add the ParkourSystem folder to your project.
Attach the Parkour Actor Component to your character.
Configure input bindings (Jump, Parkour, Interact).
Adjust obstacle detection parameters to fit your level design.
